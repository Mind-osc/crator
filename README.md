# Crator

Android launcher εμπνευσμένος από Nova, Niagara, Smart Launcher, Action Launcher και Lawnchair, με **ενσωματωμένο Claude**: swipe κάτω στην αρχική και ανοίγει κομψό παράθυρο συνομιλίας.

## Λήψη
Κάθε push στο `main` χτίζει το APK μέσω GitHub Actions → **Releases → latest → Crator.apk**.

## Χαρακτηριστικά (v0.1)
- **Claude**: swipe κάτω, streaming απαντήσεις, φωνή, άνοιγμα εφαρμογών με εντολή, γρήγορη αναζήτηση εφαρμογών, 3 στυλ παραθύρου, κρυπτογραφημένο API key
- **Ταμπλό συστήματος** (αριστερή σελίδα): CPU (ανά πυρήνα), RAM, χώρος, δίκτυο (↓/↑), μπαταρία, θερμικά, με γραφήματα που τρέχουν μόνο όταν βλέπεις τη σελίδα + 16 συντομεύσεις (Ρυθμίσεις, Αρχεία, Wi-Fi, φακός…)
- **Εικονίδια**: 11 σχήματα, μέγεθος, κλίμακα, αδιαφάνεια, κορεσμός, σκιά, περίγραμμα, φόντο, themed (μονόχρωμα), icon packs (Nova/ADW), εικονίδιο ανά εφαρμογή, μετονομασία, ετικέτες (μέγεθος/χρώμα/γραμμές/σκιά)
- **Dock**: 7 στυλ (Αιωρούμενο, Γυαλί, Νησί, Κλασικό, Χωρίς φόντο, Καρουζέλ, Τόξο), στοίχιση, χρώμα, αδιαφάνεια, γωνίες
- **Εφέ**: 12 εφέ αλλαγής σελίδας, 9 κινήσεις ανοίγματος εφαρμογής, εφέ πατήματος, ταχύτητα, blur
- **Χειρονομίες**: swipe πάνω/κάτω, διπλό tap → ό,τι θες
- **Συρτάρι**: πλέγμα ή λίστα, αναζήτηση χωρίς τόνους, «Ρώτα τον Claude», κρυφές εφαρμογές
- App shortcuts, απεγκατάσταση, πληροφορίες, backup/επαναφορά ρυθμίσεων
